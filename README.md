# pull-shark-demo 🦈

This repository demonstrates how to earn the **Pull Shark badge** on GitHub by creating and merging pull requests.

## Features
- Creating branches
- Making commits
- Opening Pull Requests
- Merging Pull Requests
- Understanding GitHub contribution workflow

## Purpose
This project is created for learning and demonstrating the GitHub Pull Request workflow and earning the Pull Shark achievement.

## Tech Used
- Git
- GitHub
